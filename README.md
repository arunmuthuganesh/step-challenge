# Step Challenge

Android app for daily step challenges with friends. Steps sync automatically from Samsung Health or any app that writes to Health Connect, and the group leaderboard (with fines for missed days) is shown in the app.

This repository only hosts the app releases.

## Install

Download **StepChallenge.apk** from the [latest release](https://github.com/arunmuthuganesh/step-challenge/releases/latest/download/StepChallenge.apk), open it and allow installing unknown apps if asked. Install steps: https://step-challenge-arun.web.app

## Automatic updates

Install [Obtainium](https://github.com/ImranR98/Obtainium) and add `https://github.com/arunmuthuganesh/step-challenge`.
